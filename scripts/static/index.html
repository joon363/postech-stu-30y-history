📱 핸드폰 카메라 연결 (2가지 방법)

✨ USB 연결의 장점: 브라우저 보안 경고가 전혀 뜨지 않으며, localhost로 인식되어 카메라가 100% 즉시 켜지고 전송 속도가 가장 빠릅니다.
  1. 스마트폰을 USB 케이블로 노트북에 연결합니다.
  2. 스마트폰 [설정] - [개발자 옵션] - [USB 디버깅]을 켭니다.
  3. 아래 '⚡ ADB 포트포워딩 실행' 버튼을 클릭합니다.
  4. 스마트폰 크롬/삼성인터넷 주소창에 아래 주소를 입력합니다:
http://localhost:8000/mobile

스마트폰 카메라로 아래 HTTPS QR 코드를 스캔하세요:

https://192.168.0.164:8443/mobile
⚠️ 1회성 자체서명 인증서 통과 방법:
화면에 "연결이 비공개로 설정되어 있지 않습니다" 경고가 뜨면,
화면 아래쪽 [고급] 버튼을 누른 후 [안전하지 않음으로 이동 (계속)]을 누르면 카메라가 정상 허용됩니다.
