# 30년사 마크다운 교정 에이전트 지침서 (format_agent.md)

---

## 1. 기본 원칙
1. **코드 미사용 (순수 문맥 교정)**:
   - 정규식(Regex) 스크립트나 일괄 치환 파이썬 코드 등을 돌리지 않고, 순수하게 문맥, 어휘 사전, 도메인 지식을 바탕으로 직접 교정합니다.
2. **환각(Hallucination) 방지**:
   - 원문이 뭉개지거나 누락되어 유추가 불가능하거나 모호한 경우 절대 임의로 지어내지 않고 `[확인필요: 원문 ... / 설명]` 마커를 명시합니다.
3. **어휘 사전 지속 동기화 (`global_voca.md`)**:
   - 작업 도중 새로운 고유명사, 행사명, 기구명, 간행물, 제도 등이 발견되면 즉시 루트 디렉터리의 [global_voca.md]에 한 줄 설명과 함께 추가합니다.

---

## 2. 마크다운 포맷팅 규칙
- **페이지 보존**:
  - `<!-- Page N -->` 주석은 절대 삭제하거나 변경하지 않습니다.
  - 페이지 사이 구분은 `---`로 깔끔하게 정리합니다.
- **제목 계층 구조**:
  - 챕터/대주제: `# 제목`
  - 섹션/자치단체/연표 구간: `## 제목`
  - 세부 연도 / 소제목: `### 제목`
- **연표 및 리스트**:
  - 연표는 `### YYYY년` 아래에 `- ` 불릿 리스트 형태로 정리합니다.
  - 임원진/명단은 `- 이름(학과학번 | 대수)` 형태로 규격화합니다.

---

## 3. 자주 발생하는 OCR 오류 교정 패턴
- **학과 약칭 표준화**:
  - `창공`, `강공` → `창의IT` (창의IT융합공학과)
  - `산경`, `산공`, `/한경` → `산경` (산업경영공학과)
  - `소제`, `소재` → `신소재`
- **숫자 / 퍼센트 깨짐**:
  - `920/` → `92.0%`, `700/0` → `70.0%`, `996` → `9.9% [확인필요]`
- **자주 깨지는 고유명사/단체명**:
  - `라은` → `도서관 자치위원회 라온`
  - `기숙사가기회` → `기숙사자치회`
  - `태율제` → `태울제` (KAIST 축제)
  - `제패` → `제1대`
  - `식질 개신` → `식질 개선`
  - `것 모바일` → `첫 모바일`
  - `기부치1납` → `기부채납`

---

## 4. 작업 워크플로우 (Step-by-Step)
1. **타깃 파일 확인**: md 내용을 확인합니다.
2. **도메인 대조**: global_voca.md 를 참조하여 고유명사 일치 여부를 대조합니다.
3. **수정본 작성**:
   - `<!-- Page X -->`를 유지하며 문맥에 맞게 오탈자 교정 및 헤더/리스트 서식 적용.
   - 모호한 곳은 `[확인필요: ...]` 처리.
   - 사진이 필요한 경우 /uploads에서 해당하는 페이지를 찾아서 보기 (시간이 오래 걸리므로 정말 어려운 경우 사용)
4. **용어집 업데이트**: 새로 파악된 고유 어휘를 global_voca.md에 반영.
5. **저장 및 검토**: md 를 덮어쓰고 이상 여부를 점검합니다.
